FollowTidy — free edition

Version 0.3.0 free beta. Completely free, with no FollowTidy daily, monthly, lifetime or batch-size cap. No subscription, payment setup or account key is needed.

Install in Chrome

  1. Extract FollowTidy-v0.3.0.zip into a separate folder.
  2. Open chrome://extensions and enable Developer mode.
  3. Click Load unpacked and select the extracted folder containing manifest.json.
  4. Open FollowTidy from Chrome's Extensions menu. The dashboard should say Your free edition.
  5. Disable the old FollowTidy extension while using this one so two queues cannot operate on the same Instagram account.

Use it

Sign in to the correct Instagram account in the same browser and use Instagram in English. Import every followers JSON part plus following.json from your recent, all-time export, or enter usernames manually. Tick the accounts to unfollow, review the list, then start. Unticked accounts are not processed.

  • “Sorry, this page isn't available” or “this page is not available”: skip that profile and go to the next selected ID.
  • Already not following: skip that profile.
  • Success: record the result and continue.
  • Login prompts, account restrictions, changed controls or uncertain results: stop for your attention.

Keep the dashboard open. It waits 30 seconds after a successful unfollow and 2 seconds after a skipped profile. Stop prevents further clicks; a request already submitted can still complete. There is no automatic resume or retry.

No app limit does not mean Instagram has no limits. This edition retains the existing pacing and restriction checks. Live Instagram behavior has not been verified in this session; its layout can change.

Imported lists stay in the open dashboard's memory and are discarded when it closes or reloads. Temporary run controls and the most recent submitted target are stored locally. No billing service is contacted. No subscription or paid upgrade is offered.
